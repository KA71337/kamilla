# 9Ч — Официальная платформа голосования класса

Современный веб-сервис для проведения анонимных голосований в 9Ч классе в режиме реального времени.

![9Ч Голосование](kamila.png)

## ⚡ Особенности и функционал

- **Real-Time синхронизация:** мгновенное обновление результатов, процентов и количества участников через **Socket.IO**.
- **Премиальный тёмный дизайн:** неоновые акценты, стеклянный интерфейс (Glassmorphism), плавные адаптивные анимации.
- **Мобильная адаптивность:** оптимизировано для смартфонов (iOS / Android) и настольных компьютеров.
- **Честность и анонимность:** 
  - Защита от повторного голосования с одного устройства (LocalStorage + UUID сессии).
  - Никаких персональных данных, фамилий или телефонов не запрашивается.
- **Хранение данных:** голоса хранятся исключительно в оперативной памяти сервера (in-memory `Map`). **Никаких внешних баз данных (PostgreSQL, SQLite и др.) не требуется.** При перезапуске сервера счётчики обнуляются.
- **Устойчивость сети:** обработка отключений, индикация статуса и автопереподключение WebSocket с синхронизацией состояния.

---

## 🛠 Стек технологий

- **Backend:** Node.js, Express, Socket.IO, HTTP.
- **Frontend:** Нативный HTML5, CSS3 (Glassmorphism, Flexbox, CSS Grid), Vanilla JavaScript (ES6+).
- **Хостинг:** Готов к деплою на Render, Railway, Koyeb или VPS.

## 🚀 Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/KA71337/kamilla.git
   cd kamilla
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер:
   ```bash
   npm start
   ```

4. Откройте в браузере:
   ```text
   http://localhost:3000
   ```

## ☁️ Инструкция по деплою на Render

Проект полностью настроен для бесплатного и быстрого деплоя на [Render.com](https://render.com/):

1. Зайдите в панель управления **Render Dashboard** и нажмите **New +** → **Web Service**.
2. Подключите ваш GitHub-репозиторий: `KA71337/kamilla`.
3. Укажите параметры сервиса:
   - **Name:** `class-9ch-voting` (или любое другое)
   - **Region:** Frankfurt (EU) или любой ближайший
   - **Branch:** `main`
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`
4. **Переменные окружения (Environment Variables):**
   - Настройка баз данных **НЕ требуется**.
   - Переменная `PORT` задаётся платформой Render автоматически (сервер считывает `process.env.PORT`).
5. Нажмите **Deploy Web Service**. Через 1–2 минуты сайт станет доступен по публичной ссылке формата `https://<ваш-проект>.onrender.com`.
