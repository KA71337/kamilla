# 9Ч — Голос класса

Адаптивный анонимный опрос с HTML/CSS/JS, Node.js, Express и Socket.IO. Результаты обновляются в реальном времени.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm start
```

Откройте http://localhost:3000

## Деплой на Render

1. Создайте GitHub-репозиторий и загрузите эти файлы.
2. На Render нажмите **New → Web Service** и подключите репозиторий.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Для сохранения голосов между перезапусками подключите PostgreSQL на Render и добавьте переменную окружения `DATABASE_URL` с Internal Database URL.
6. Запустите деплой. Render задаёт переменную `PORT` автоматически.

Если `DATABASE_URL` не задан, сервер использует память процесса. Это подходит только для теста: голоса сбросятся при перезапуске или новом деплое.

## Важно

- Опрос не просит имён, email или телефонов.
- Ограничение «один голос» основано на идентификаторе браузера и не является защитой от целенаправленного обхода.
- Для настоящего выбора представителя класса или решения школьного конфликта используйте согласованный и уважительный формат; не публикуйте персональные данные и списки людей, голосовавших против конкретного ученика.
